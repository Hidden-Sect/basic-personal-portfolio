# Hidden Sect Basic - Personal Portfolio

A clean, minimalist personal portfolio website built with HTML and CSS. No JavaScript required! Perfect for developers, students, and freelancers who want to showcase their skills, projects, and contact information.

## ✨ Features

- **Single Page Design**: Smooth scrolling between sections
- **Responsive Layout**: Looks great on desktop, tablet, and mobile devices
- **Modern Design**: Light theme with blue/purple gradient accents
- **Sections Included**:
  - **Hero**: Name, tagline, and call-to-action button
  - **About**: Profile image, bio, and personal details
  - **Skills**: Visual skill bars with icons
  - **Work**: Three featured projects with descriptions
  - **Contact**: Email and social media links
  - **Footer**: Copyright and back-to-top link
- **Interactive Elements**:
  - Smooth scroll navigation
  - Hover effects on buttons and cards
  - Animated hero section
  - Back-to-top button

## 🚀 Technologies Used

- **HTML5**: Semantic markup
- **CSS3**: Flexbox, Grid, animations, and transitions
- **Google Fonts**: Inter and Poppins typefaces
- **SVG**: Icons and placeholder images

## 🎨 Customization

To personalize this portfolio for yourself:

1. **Edit `index.html`**:
   - Update the name and tagline in the Hero section
   - Modify the bio and details in the About section
   - Adjust skills and skill levels
   - Replace project titles, descriptions, and tags
   - Update email and social media links

2. **Edit `style.css`**:
   - Change color scheme by updating CSS variables in `:root`
   - Adjust fonts by modifying the Google Fonts import
   - Customize spacing, sizes, and animations

3. **Replace images in `assets/`**:
   - Add your own profile picture (replace `profile.svg`)
   - Add screenshots of your projects (replace `project1.svg`, etc.)

## 🌐 Deployment

### GitHub Pages

1. Push this repository to GitHub
2. Go to repository Settings → Pages
3. Under "Source", select the main branch
4. Click Save
5. Your site will be available at `https://yourusername.github.io/basic-personal-portfolio/`

### Other Platforms

This portfolio can be deployed to any static hosting service:
- **Netlify**: Drag and drop the folder or connect your GitHub repo
- **Vercel**: Import your GitHub repository
- **Cloudflare Pages**: Connect your GitHub repository
- **Firebase Hosting**: Use `firebase deploy`
